# Portfolio Highlights

이 디렉터리는 공개용 포트폴리오에서 강조할 핵심 설계만 정리한 예시입니다.

## 구성

- AI/ : 로컬 ComfyUI 기반 실험 도구
- Gameplay/Interfaces : 아이템/드래그 인터페이스 설계
- Gameplay/Systems : 역할 시스템 및 상호작용 흐름 예시

## 포트폴리오 목적

이 디렉터리의 코드는 전체 프로젝트를 그대로 공개하는 대신,
다음 질문에 답할 수 있도록 정리된 예시입니다.

- 아이템 상호작용을 어떻게 추상화했는가?
- 서버 중심으로 역할과 권한을 어떻게 분리했는가?
- 멀티플레이어 입력과 상태 변화가 어디에서 처리되는가?
- AI 실험 도구는 프로젝트의 핵심 기능이 아니라 어떤 의미를 가지는가?

## 핵심 원칙

- 런타임 게임 로직 중심으로 설명할 수 있는 부분만 유지
- 외부 API, 로컬 환경 의존, 민감 정보는 공개용 설명에서 분리
- 인터페이스 설계와 시스템 구조를 먼저 보여줌
- AI는 "킥"으로 보이되 메인 기능으로는 보이지 않게 정리
